### PAYMENT EXPERIENCE — IMPORTANT

Design a modern, trustworthy payment experience inspired by polished Indian e-commerce/UPI checkout flows.

The payment experience should feel simple, professional, and reassuring rather than looking like a basic form.

Use the reference payment experience as inspiration for:

* Payment layout
* Information hierarchy
* QR presentation
* UPI payment flow
* Payment confirmation
* Screenshot/proof upload
* Success states

Do NOT copy another website's UI pixel-for-pixel. Create an original payment experience matching my gift hamper brand.

### PAYMENT SCREEN

After the customer reaches payment, create a dedicated, visually clean payment section.

Show:

* Order total prominently
* Selected payment method
* Large, clearly visible UPI QR code
* UPI payment instructions
* UPI ID where applicable
* "Pay Now" / "Scan & Pay" CTA
* Payment status
* Payment screenshot upload option
* Order ID/reference number
* Clear confirmation message

The QR code should be visually prominent but should not dominate the entire screen.

### PAYMENT METHOD SELECTION

Create a clean payment-method selector.

Possible options:

* UPI / QR
* Other payment methods if already supported

Use modern selectable cards with:

* Payment icon
* Payment method name
* Short description
* Selected state
* Smooth transition

Do not add payment methods that the existing website/backend does not actually support.

### UPI PAYMENT FLOW

Create this simple visual flow:

1. Review order
2. Select UPI
3. Scan QR / use UPI ID
4. Complete payment in UPI app
5. Return to website
6. Upload payment screenshot
7. Submit order
8. Show payment/order confirmation

Make these steps visually obvious so a first-time customer knows exactly what to do.

### QR CODE PRESENTATION

Design a premium QR payment card containing:

* QR code
* "Scan to Pay" heading
* Amount
* UPI ID
* Short instruction such as:
  "Scan this QR using any supported UPI app."
* Optional supported UPI app icons if appropriate

Add a subtle visual frame around the QR code so it is easy to identify.

Do not distort, crop, or decorate the actual QR code in a way that could affect scanning.

### PAYMENT SCREENSHOT UPLOAD

After payment, provide a clear upload area:

"Payment completed? Upload your screenshot"

Include:

* Drag-and-drop/upload area
* Upload button
* Image preview after upload
* Replace/remove option
* Upload progress
* Successful upload state
* Error state

Make it clear that the screenshot is used to verify the payment.

### PAYMENT VERIFICATION STATE

After submitting the screenshot, show:

"Payment verification pending"

Include:

* Order/reference number
* Payment status
* Short explanation that the order will be verified
* What the customer should expect next
* Contact/update option if already supported

Use a polished status indicator rather than simply displaying plain text.

### SUCCESS EXPERIENCE

After successful order submission, create a beautiful confirmation screen.

Include:

* Animated success/checkmark
* "Order placed successfully"
* Order number
* Amount paid
* Payment verification status
* Order summary
* Expected next step
* Button to continue shopping
* Contact/update information if supported

Use a subtle celebratory animation appropriate for a gift brand.

For example:

* Soft confetti
* Gentle sparkle
* Smooth checkmark animation

Keep it elegant and avoid excessive celebration.

### PAYMENT MICRO-INTERACTIONS

Add subtle motion to the payment experience:

* Payment method selection smoothly transitions
* QR card gently appears
* Amount transitions smoothly
* Upload area responds to hover/tap
* Screenshot preview animates into place
* Upload progress animates
* Verification status transitions smoothly
* Success checkmark draws/animates into view
* Order confirmation elements appear with a subtle stagger

### PAYMENT SECURITY / TRUST DESIGN

Make the payment section visually trustworthy.

Include subtle indicators such as:

* Secure payment messaging
* Payment verification information
* Clear order ID
* Clear amount
* No confusing redirects
* No unnecessary form fields

Do not make fake security claims or display certifications/badges unless they actually exist.

### IMPORTANT EXISTING FUNCTIONALITY

The current website already supports:

* Payment QR
* Payment screenshot upload
* Cloudinary image upload
* Firebase/Firestore order storage
* Admin-side payment/order verification

The new UI must be designed around these existing capabilities.

Do NOT replace the current payment system with a different payment gateway.

Do NOT assume Razorpay, Stripe, PayPal, or another gateway is available unless it already exists in the project.

### MOBILE PAYMENT EXPERIENCE

The payment screen must be especially optimized for mobile because many customers will complete UPI payments from their phones.

On mobile:

* QR should remain clearly visible
* Payment instructions should be short
* Upload screenshot should be easy
* Buttons should be thumb-friendly
* Amount should remain visible
* Important status information should appear above the fold where possible
* Avoid unnecessary scrolling
* Keep the payment process extremely simple

### PAYMENT UX GOAL

The customer should understand the entire process within a few seconds:

"Here is my amount → scan/pay → upload proof → place order → payment verification."

The final payment UI should feel like a polished, trustworthy Indian e-commerce checkout while still matching the warm, premium aesthetic of my handmade gift hamper brand.
